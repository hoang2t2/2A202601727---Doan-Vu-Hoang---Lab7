🏷️ Metadata Schema
5 trường bắt buộc + 3 trường mở rộng cho corpus thư viện USSH.
doc_id
string
Định danh duy nhất, dùng truy vết nguồn gốc.
"noi-quy-chung"
audience
string — ⭐ K3
Đối tượng áp dụng. Lọc chính xác tránh nhầm quy định nhóm khác.
"student" | "all"
source_url
string — ⭐ K3
URL nguồn gốc, đảm bảo minh bạch và kiểm chứng.
"local_pdf/11717.pdf"
retrieved_at
date — ⭐ K3
Ngày lấy dữ liệu để biết tài liệu có thể đã lỗi thời.
"2026-08-03"
document_version
string — ⭐ K3
Phiên bản ban hành để phân biệt nhiều phiên bản cập nhật.
"2026.1"
department
string
Phòng ban sở hữu. Hữu ích khi mở rộng sang đa phòng ban.
"ussh-library"
category
string
Phân loại tài liệu (nội quy, biểu mẫu) để ưu tiên đúng loại.
"regulations"
language
string
Ngôn ngữ tài liệu cho hệ thống đa ngôn ngữ.
"vi"
